Comentarios y mejoras

Esta beta gratuita de WEB MATES está desarrollada con IA, en castellano y catalán. Ha superado pruebas automáticas, pero no cuenta con revisión humana especializada ni está homologada. Queremos corregir errores y mejorarla con quienes la utilicen.

¿Cómo puedes colaborar?

Si utilizas GitHub

Abre una incidencia para comunicar errores y propuestas. Si sabes corregir código o contenido, abre una pull request (PR). Los mantenedores revisarán los cambios antes de incorporarlos.

Abrir una incidencia en GitHub Ver o proponer pull requests

Si no utilizas GitHub

Escribe tu comentario aquí. Al pulsar «Preparar correo» se abrirá tu aplicación de correo para que lo envíes tú. El sitio no recibe mensajes automáticamente ni muestra comentarios públicamente. También puedes copiarlo y enviarlo desde otra aplicación de correo.

Privacidad y moderación

No envíes información personal de menores ni datos académicos identificables. Al enviar el mensaje desde tu correo, tu dirección y su contenido se tratarán en el buzón de contacto según la política de privacidad. Este formulario no tiene base de datos, analítica ni un muro público de comentarios. Los mantenedores revisarán los mensajes recibidos y decidirán qué propuestas trasladar a GitHub o a la web.
