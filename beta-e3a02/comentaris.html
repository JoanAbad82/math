Aquesta beta gratuïta de WEB MATES s’ha desenvolupat amb IA, en castellà i català. Ha superat proves automàtiques, però no disposa de revisió humana especialitzada ni està homologada. Volem corregir errors i millorar-la amb les persones que la facin servir.

Com hi pots col·laborar?

Si fas servir GitHub

Obre una incidència per comunicar errors i propostes. Si saps corregir codi o contingut, obre una pull request (PR). Els mantenidors revisaran els canvis abans d’incorporar-los.

Obre una incidència a GitHub Consulta o proposa pull requests

Si no fas servir GitHub

Escriu el comentari aquí. En prémer «Prepara el correu», s’obrirà l’aplicació de correu perquè l’enviïs tu. El web no rep missatges automàticament ni mostra comentaris públicament. També el pots copiar i enviar des d’una altra aplicació de correu.

Privacitat i moderació

No enviïs informació personal de menors ni dades acadèmiques identificables. En enviar el missatge des del teu correu, l’adreça i el contingut es tractaran a la bústia de contacte segons la política de privacitat. Aquest formulari no té base de dades, analítica ni un mur públic de comentaris. Els mantenidors revisaran els missatges rebuts i decidiran quines propostes traslladen a GitHub o al web.
