## Participar

- Comunicar error o sugerencia: [GitHub Issues](https://github.com/JoanAbad82/math/issues).
- Proponer corrección: crea una rama en tu fork y abre una **pull request cuyo destino (base) sea beta-e3a02-publica**, modificando exclusivamente los archivos pertinentes de esta carpeta.
- Sin GitHub: [comentarios por correo desde la web](https://webmates-e3a02-beta.pages.dev/comentarios.html) (no es un muro público).
- Indica el ID de ejercicio o lección, pasos de reproducción, comportamiento esperado, prueba matemática cuando proceda y los dos idiomas afectados. No incluyas datos personales de menores.
- Los mantenedores examinan cada PR antes de incorporarla. **Ningún PR se despliega automáticamente**: los cambios aprobados necesitan reconstrucción, pruebas, nuevo ZIP/SHA-256 y publicación autorizada.
